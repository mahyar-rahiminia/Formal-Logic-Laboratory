# Formal-Logic-Laboratory
A public learning warehouse documenting my progression toward research in justification logic, proof theory, and modal logic through formal proofs, exercises, constructions, and structured notes.

## Purpose

This repository is not intended to be a collection of copied notes or a record of completed textbooks.

Its purpose is to preserve the development of my formal reasoning skills and to build a reusable foundation for future research.

The emphasis is on:

* formal proofs
* problem solving
* mathematical and logical definitions
* proof strategies
* constructions and counterexamples
* mistakes, corrections, and improved solutions
* connections between logical systems

## Current Focus

I am currently building the mathematical and logical foundations required for deeper work in:

**Justification Logic × Proof Theory × Modal Logic**

The immediate focus is on developing strong proof and metatheoretic skills before moving toward specialized research problems.

## Repository Structure

### `proofs/`

Proofs developed independently while studying.

Each proof should ideally preserve:

* the statement
* the proof
* the main method
* the key idea
* relevant source

### `concepts/`

Compact, operational notes on concepts and techniques that I expect to reuse.

These are not intended to reproduce textbook explanations. They focus on what a concept means, when it is useful, and how it functions in actual problem solving.

### `problems/`

Exercises and problem-solving attempts.

When useful, these may include:

* the original attempt
* the mistake or obstacle
* the corrected solution
* a later, cleaner solution

## Method

The basic learning cycle is:

**Read → Reconstruct → Solve → Review → Commit**

A concept is considered learned when I can use it independently, not merely recognize it after reading.

## Long-Term Direction

The long-term goal is to develop the technical foundations necessary for independent research in formal logic, with particular emphasis on:

* Justification Logic
* Proof Theory
* Modal Logic

and their connections to broader areas of mathematical and formal epistemology.

Ultimately, the aim is to move from learning existing results to producing original mathematical results such as **theorems, constructions, counterexamples, or characterizations**.

---

*This repository documents the process of becoming capable of doing that.*
